# 评估集说明

## 1. 构成

| 评估集 | 规模 | 用途 |
|---|---|---|
| 自建风控评估集 `domain_eval.yaml` | 101 题（dev 41 / test 60） | 端到端、路由、槽位、执行准确率 |
| BIRD financial（2025-11-06 清洗版） | 106 题（simple 24 / moderate 25 / challenging 57） | 第三层外部基准，由 `scripts/download_data.py` 下载 |

自建集题型：L1（OKR 物化表）16、L2（语义层编译）35、L3（生成式 SQL）30、CLARIFY 10、OOD 5、META 5。

划分规则：各类别内按序号 i（从 1 开始），i mod 5 属于 {1, 3} 的题目划入 dev，其余为 test。评估集先于系统开发冻结，test 集只用于最终报告。

## 2. 基准约定

| 类别 | 约定 |
|---|---|
| 参考日期 | 1998-12-31（数据截止日，配置项 `REFERENCE_DATE`） |
| 相对时间 | 今年 1998；上个月 1998-11；上季度 1998 年第三季度；近 N 个月包含当月；今年以来 1998-01-01 至 1998-12-31 |
| 未指定时间 | 不限时间，统计全部历史数据，并在答案中注明 |
| 周期 | 自然年、自然季度、自然月；上半年为 1 至 6 月 |
| 对比 | 同比为上一年同期；环比为紧邻的上一个同长度周期 |
| 业务口径 | 以 `semantic/metrics.yaml` 为准（不良为状态 B 或 D；不良率按放款日期归属；出账含 VYDAJ 与 VYBER） |
| 输出 | 分组类只列有数据的组；比率以小数表示；趋势周期格式为 YYYY-MM、YYYY-Qn、YYYY |

## 3. 判定规则

| 指标 | 规则 |
|---|---|
| EX（BIRD 官方） | 预测结果集与金标结果集按集合严格相等 |
| EX（宽松，自建集） | 金标每一列映射到预测结果的不同列且行级一致，允许额外说明列；数值允许 1 至 4 位小数的舍入差异；仅排序类题目比较行序 |
| 槽位准确率 | 预测 IR 与金标 IR（或语义等价的备选 IR）逐槽位比较 |
| 路由准确率 | 预测路由与标注路由一致 |

## 4. 金标校验

| 层次 | 方法 | 结果 |
|---|---|---|
| 机器校验 | `scripts/check_eval_set.py`：全部金标 SQL 执行、非空、耗时；TopN 边界无并列 | 101 / 101；BIRD 106 / 106 可执行 |
| 勾稽校验 | `scripts/crosscheck_eval.py`：同一数量经两条独立路径计算必须一致 | 20 / 20 |
| 人工语义审阅 | `review_checklist.md`：抽样 20 题按指标、时间、筛选、分组核对口径 | 全部符合 |
| 自检 | `tests/test_eval_harness.py`：金标回放各项指标均为 100% | 通过 |
